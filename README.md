# C# Backend Practice

Repositório criado para organizar práticas e pequenos projetos desenvolvidos durante a minha aprendizagem em desenvolvimento backend.

Aqui reúno exercícios, testes, anotações e projetos relacionados com C#, SQL, ASP.NET Core Web API, Entity Framework Core e bases de dados.

## Conteúdo do repositório

- Práticas com C# e Programação Orientada a Objetos
- Exercícios e anotações de SQL
- Projetos de API REST com ASP.NET Core
- Testes de ligação a bases de dados
- Práticas com Entity Framework Core
- Organização de código em models, controllers e DbContext

## Tecnologias e ferramentas

- C#
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- MySQL
- Postman
- Swagger
- Git e GitHub
- Visual Studio

## Objetivo

O objetivo deste repositório é acompanhar a minha evolução como programador backend júnior, praticando conceitos fundamentais através de projetos simples e exercícios práticos.

Este repositório está em constante evolução conforme continuo a estudar e melhorar os projetos.
